  no pixel golden comparison across hosts.

- Hash is validated with the stored `hash_version`; only v1 exists, so future visual bumps must add a versioned hasher.
- No golden image across hosts/fonts; E2E still uses preset backgrounds instead of a real Cloudinary frame.
- No social publishing, scheduling, paid image API, GPU or viral prediction.
