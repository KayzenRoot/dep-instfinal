## Database / integrity

- `style_presets`, `style_preset_revisions`, `episode_style_overrides`,
  `scene_style_overrides`: forced RLS, owner-select only, `service_role` writes via
  SECURITY DEFINER RPCs.
- Revisions immutable (`55000`), optimistic revision check (`40001`), invalid scope
  (`23514`), direct authenticated writes denied (`42501`), second owner sees zero rows.
- Quota trigger allows 200 revisions per preset and blocks the 201st with
  `style_revision_quota`.
- Clear RPCs (`clear_episode_style_override`, `clear_scene_style_override`) are
  service-role only, validate the owner scope, and return the row to inheritance.
- Config is a strict allowlist: enums, `#rrggbb`, known template IDs, owner-scoped SFX
  UUIDs; no URLs, binaries, shell or FFmpeg filters. The import envelope is strict too.
- SFX references are validated against `audio_assets` license flags on preset/override
  save and re-audited on snapshot resolution; missing/unlicensed IDs are removed and
  reported as warnings.

## Render / preview

- The render/export path applies the frozen style snapshot to captions: `horror` →
  VHS treatment, `clean` → clean, plus the safe zone and ASS font family. Plans
  without `styleBible` keep the legacy behavior.
- The timeline only applies a new style on a new plan or when **“Aplicar estilo atual”**
  is checked (or rebuild); normal saves preserve the stored snapshot, and legacy plans
  without a snapshot are flagged instead of silently changed.
- `/app/finale` uses `endCardTemplateId` and `ctaPrompt` as defaults for a new card;
  `/app/covers` preselects `coverTemplateId` when a style exists.
- `/app/style` shows a synthetic sample clip with caption, CTA, the first licensed SFX
  audio, the approved cover image via the private API, the approved end-card
  revision and the approved narration take audio; SFX application remains a documented reference.
