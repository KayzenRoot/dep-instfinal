# WO-008 — real ASR and documented CLI evidence

Date: 2026-11-14
Environment: local Supabase, Piper `pt_BR-cadu-medium`, Vosk `vosk-model-small-pt-0.3`.

## Opt-in integration test

Command (env abbreviated to names):

```text
VOSK_MODEL=... VOSK_PYTHON=... PIPER_MODEL=... PIPER_PYTHON=... \
  npx vitest run src/lib/server/caption-asr.integration.test.ts

1 passed (8,1 s)
```

The test synthesizes a two-sentence pt-BR script with Piper, transcribes it with the
real Vosk helper via stdout, probes the audio duration with ffprobe, and aligns the
known script. Result: `FORCED_ALIGNMENT`, score > 0,5, > 8 ASR words, final text
contains “Alice reconheceu”.
