9) Design notes
- Additive migration 20261113090000_v2_wo004_edit_plans.sql.
- Plan write RPCs are executable only by service_role; the SvelteKit server
  validates the full plan, computes SHA-256 and passes the verified owner id.
  Tables expose SELECT only to authenticated; direct RPC/insert/update is denied.
- Every RPC checks published status and NULL/stale expected_version; restore
  revalidates the source snapshot; load verifies the stored canonical hash.
- Plan revision binding and global scene uniqueness are enforced in the domain.
- Plan versions are immutable; restore appends a new snapshot.
- Manifest hash is SHA-256 of canonical sorted-key JSON.
- No video bytes are stored in PostgreSQL; plans reference READY video_assets.
