## Database / retention

- `published_posts`, `published_post_versions`, `creative_variants`, `analytics_snapshots`,
  `retention_imports`, `retention_experiments` are owner-read/service-write with forced RLS.
- Snapshots/versions/imports are immutable; snapshots are idempotent by `(post, snapshot_hash)`
  that includes `episode_duration_ms`, pin `metric_version`, and retifications append a new revision
  with `supersedes_snapshot_id`.
- Experiments pin `variant_a_snapshot_id`/`variant_b_snapshot_id` and reject variants from the same
  post; concurrent snapshot revisions use an advisory lock.
- PgTAP: owner read, direct insert denied, second owner isolated, post version, variants A/B,
  idempotent snapshot, supersedes, immutable update, experiment distinct variants, delete cascade.
- Quota: 5000 snapshots per post; 5000 CSV rows and 5 MB input.

## Privacy / security

- URLs are owner-provided text and never fetched; no scraping, login automation or social API.
- Only aggregate metrics are stored; no viewer-level, demographic or comment data.
- Export routes owner-only, `private, no-store`; CSV cells are quoted then prefixed per line
  against formula injection.
- Deletion is owner-scoped and removes post, versions, variants, snapshots and linked experiments.

## Limits verified

- Comparisons are descriptive associations, not causal or significance tests.
- Different platforms or window lengths return `NOT_COMPARABLE`; low samples return `INSUFFICIENT`.
- CSV export contains the latest snapshot per post; full context and imports are in JSON.
- Post edits create a new version; variants are immutable and have no edit UI.
